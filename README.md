# Space Invaders (Unity)

My first game: a classic Space Invaders clone made with Unity 6.

## How to play

| Key | Action |
|---|---|
| Left / Right arrows or A / D | Move |
| Space | Shoot |
| P | Pause |
| Enter | Start / play again |

Shoot every invader before they land. Hide behind the green shields, and hit the red UFO for bonus points!

## Project layout

- `Assets/SpaceInvaders/Scripts` – game code (C#)
- `Assets/SpaceInvaders/Editor` – the **Space Invaders > Build Game Scene** setup tool
- `Assets/SpaceInvaders/Sprites`, `Prefabs`, `Scenes` – created by the setup tool
